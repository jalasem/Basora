# Basora Privacy Policy

Effective date: August 23, 2026

Basora - Docs to README ("Basora") converts documentation pages selected by the user into Markdown files. This policy explains how the extension handles information.

## Information Basora handles

When the user starts a capture session, Basora processes the URL and visible content of documentation pages that the user chooses to capture. This can include text, headings, links, code examples, images, diagrams, and direct public video URLs found on those pages.

Basora also stores the active session, captured page content, custom output filename, navigation timing preference, and any user-chosen "Next" button selector in Chrome's local extension storage.

## How information is used

The information is used only to provide Basora's user-facing purpose: extracting selected documentation, navigating documentation pages when requested, and creating a Markdown or ZIP download on the user's device.

When Basora packages images or downloadable video files, the user's browser may request those files directly from their original public URLs. Basora does not proxy those requests through a developer-operated server.

## Local processing and retention

Basora has no developer-operated backend, account system, advertising, analytics, or telemetry. Captured page content and settings are processed and stored locally in the user's browser. Basora does not send captured content, browsing activity, or settings to the developer or to third parties.

Captured pages remain in local extension storage only while a session is active. Ending a session clears the captured pages after the download is initiated. Users can also remove all locally stored Basora data at any time by clearing the extension's data or uninstalling the extension.

## Sharing and sale of data

Basora does not sell, rent, share, or transfer user data. It does not use user data for advertising, creditworthiness, lending, or purposes unrelated to its single user-facing function.

## Permissions

Basora requests access needed to:

- read a documentation page only when the user captures it or starts auto-capture;
- run the content extractor and user-directed next-button picker;
- store sessions and preferences locally;
- save Markdown and ZIP files to the user's device;
- display the optional sticky side panel; and
- continue a user-started documentation crawl across pages and websites.

## Limited Use

Basora's use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Data access is limited to providing or improving Basora's single user-facing purpose.

## Changes

If Basora's data practices change, this policy and the extension's Chrome Web Store disclosures will be updated before the changed practices are released.

## Contact
